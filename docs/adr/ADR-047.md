# ADR-047: Floors and Layers are removed (supersedes ADR-030; amends ADR-032)

## Status

Implemented

- **Status:** built on `claude/ui-tweaks-navigation-674a2c` on 2026-10-13 and deployed. No migration.
- **Context:** Floors (one tilted floor per generation) and Layers (upright planes, one per band), both CSS 3D (ADR-030), were early work toward the 3D views. The WebGL views (ADR-032, ADR-035) replaced them, and both had been off the controls since ADR-032. The owner asked for both to be removed, one commit each.
- **Decision:**
  - **Both modes are gone,** with their layouts, canvases and the CSS 3D plane code they shared (`PlaneStack`, `plane-stack`, `plane-scale`, `plane-keyboard`, `row-placement`, the dive between generations, the camera presets and the band fade). So are the controls only they used: the phone fallback that drew Flat for Floors, the partnership a Layers view was centred on (`union=` in the address and its picker in the focus menu), the Alt+Up/Down step between bands, and the narrowed zoom range.
  - **Every remaining view has the whole tree** (ADR-046), so the `hasWholeTree` trait is gone and `scope=all` is kept whatever the mode. With no view left off the controls, the toolbar and the default-view pickers list every mode.
  - **Nothing stored needs rewriting.** A member's or tree's saved view, and the `mode` in an address, are parsed on read (`parseLayoutMode`), so `floors` and `layers` now read as no choice and the next one in line applies: the member's, then the tree's, then Flat. An old link's `union=` is ignored.
- **Consequences:** the views are Flat (the hourglass, and the whole tree) and the four WebGL overviews. The side branches and partners' families that Layers was the first to draw stay, read by the WebGL views; their arrival default is `ARRIVAL_COLLATERAL_DEPTH`. The Playwright WebKit project ran only the CSS 3D specs, so it went with them; every spec runs in Chrome. Kin placement (`kin-placement.ts`) stays: the selection every view draws from (`select.ts`) takes its bands and anchors from it.
