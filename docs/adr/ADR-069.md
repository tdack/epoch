# ADR-069: A sub-tree is shown to the public only when a manager makes it public (extends ADR-062)

## Status

Implemented

- **Status:** built on `claude/public-subtrees-visibility-e49622` on 2026-10-20. **Migration 0038 adds `subtree.is_public`** (integer, not null, default 0; expand only).
- **Context:** the public site wants to link a demo sub-tree. ADR-062 left a sub-tree visible to anyone who could see its root, with no way to keep one back, and the demo's sub-trees were not among those the owner meant to publish. The owner chose a per-sub-tree opt-in over making all of a public tree's sub-trees public, or one switch for the tree.
- **Decision:**
  - A viewer with no membership (`scope.isOutsider`: a signed-out visitor, or a signed-in stranger, reading the public tree) is shown a sub-tree only when `is_public` is set **and** its root passes the visibility predicate. Both conditions are in the same statement as the list, in `SubtreeRepository.list`, so the list, the summary that feeds the tree switcher, and `tree~slug` resolution all follow one rule.
  - Members are unchanged: any role sees every sub-tree whose root it may see, public or not. The flag only narrows what an outsider sees.
  - A sub-tree that is not public, whose root is hidden, or that does not exist is the same 404, with no hint that it exists. ADR-062's privacy rule stands.
  - The flag is set on create (`isPublic`, default false) or by PATCH, under `tree:manage_subtrees`, and is logged and undoable like the other fields. The Trees page shows a "Public" badge and a "Show to visitors" / "Hide from visitors" action.
  - Existing sub-trees stay members-only until a manager opts them in, so the deploy exposes nothing.
- **Rejected alternatives:** public by default when the root is visible (a manager could not make a lens for family use only); a tree-level switch (all or none, so the owner could not publish one demo lens).
- **Consequences:** a public sub-tree is a lens, not a boundary, so a visitor who opens it can still reach the rest of the public tree; making one public publishes nothing the tree does not already show. Covered by `subtree-public.test.ts` and the visitor cases in `load-access.test.ts`. No browser e2e: the local dev bypass signs every request in, so a signed-out visitor cannot be driven there.
