# ADR-077: Epoch is an installable PWA; its service worker caches no private data

## Status

Implemented

- **Status:** accepted and built on 2026-10-24 (not deployed).

## Context

Epoch had a web manifest and icons but no service worker, so browsers would not offer to install
it. The data behind sign-in is private family history, and a device may be shared.

## Decision

- **Epoch is installable.** The manifest gains `id` and `scope` of `/` (it lives under `/brand/`,
  so its default scope would be too narrow), and SvelteKit registers `src/service-worker.ts`.
- **The worker precaches only immutable build assets, the brand icons and manifest, and
  `/offline.html`.** The cache name carries the build `version` and older caches are deleted on
  activate.
- **Navigations go to the network.** Only if it fails is the offline page returned. No page, `/api/*`,
  `/media/*` or other dynamic response is ever put in a cache, and requests that are not same-origin
  GETs are not touched.
- **There is no offline reading.** Cached private data would outlive sign-out on a shared device.

## Consequences

An offline visitor sees a static page with a Retry link. Offline reading would need its own ADR
covering sign-out purging and per-user cache keys.
